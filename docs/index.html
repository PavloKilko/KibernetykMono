KibernetykMono

Kibernetyk [kʲibɛrˈnɛtɪk] Mono is a geometric monospace inspired by the pioneering spirit of the Ukrainian Cybernetics School. Its rigid, pared-back letterforms recall early mainframe interfaces and the ink-stamped texture of fax transmissions. Drawn from points and lines for clean code, dense data, and the infrastructure that holds them together.

GLUSHKOV SYSTEMS™
SYSTEM PROGRAMMING DIVISION

SECTION 07.2
REV 1963

============================================================
PROMIN REFERENCE MANUAL MACHINE PM-63 
============================================================

EXECUTE PROGRAM

----------------------------------------------------------------------------------------------------

[RUN]/promin/program/07

====================================================================================================

SYSTEM
STATUS
DATA

PROMIN
READY
{
    "register":  "A-07",
    "memory":    "4096 WORDS",
    "input":     "01001101",
    "output":    "IDEAS BECOME SYSTEMS"
}
----------------------------------------------------------------------------------------------------

Mount the program tape, set the instruction register to A-07, and transfer control to the operating sequence. A READY status confirms that the machine can accept the next instruction.

For arithmetic routines and storage maps, see section 07.3.

If the machine reports BUSY, reset the control register and repeat the last instruction.
